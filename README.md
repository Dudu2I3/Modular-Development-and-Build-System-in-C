# Проект "Модульная разработка и сборка в C"

Этот проект включает несколько заданий, которые демонстрируют навыки работы с модулями, сборкой программ и использованием статических и динамических библиотек в языке C:

1. **Модуль `data_module`**  
   Реализована настройка и корректная работа с программой, использующей существующие файлы и функции. Основное внимание уделено грамотному применению директив препроцессора для переиспользования кода и упрощения работы с модулями.

2. **Модуль `yet_another_decision_module`**  
   Настроена работа второго модуля с аналогичной целью — использование существующих файлов и функций с применением директив препроцессора. В процессе работы уделено внимание организации структуры и модульности кода.

3. **Makefile для `main_executable_module`**  
   Создан Makefile для сборки программы, который включает стандартные цели:
   - `clean` — удаление скомпилированных файлов.
   - `all` — сборка всех компонентов программы.
   - `rebuild` — полная пересборка программы.
   
   В результате был получен исполнимый файл, который помещается в папку `build`, а сам Makefile оптимизирован для простоты и расширяемости.

4. **Сборка статической библиотеки `data_stat.a`**  
   Включена цель для создания статической библиотеки `data_stat.a`, которая используется в проекте. Создано подключение этой библиотеки в основной исполнимый файл. Это позволило применить концепции работы с внешними библиотеками и лучше понять процессы компиляции и линковки.

5. **Сборка динамической библиотеки `data_process.so`**  
   Настроена сборка динамической библиотеки `data_process.so` с помощью Makefile. Включены изменения в основной код для использования этой библиотеки с помощью макросов, что позволило изучить работу с динамическими библиотеками, их подключение и загрузку во время выполнения программы.
